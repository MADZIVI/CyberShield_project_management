Project Overview

CyberShield is a proposed IT project aimed at designing and deploying an enterprise-grade cybersecurity monitoring and incident response system for SecureFinance (Pty) Ltd.

The Problem

SecureFinance (Pty) Ltd currently lacks a centralised security operations capability, leaving the organisation vulnerable to:

  • Ransomware attacks targeting financial data
  • Phishing campaigns against staff
  • Data breaches exposing client information
  • No real-time threat visibility
  • No structured incident response process

The Solution

CyberShield implements Microsoft Sentinel SIEM integrated with:

  • Automated incident response workflows
  • Endpoint detection and response (EDR) tools
  • Staff cybersecurity awareness training
  • POPIA compliance monitoring module
  • Real-time alert system via email & SMS

Project Objectives

01

Reduce MTTD by 60%

Reduce the organisation's mean time to detect threats by 60% through centralised logging and automated correlation.

02

24/7 Security Monitoring

Establish a round-the-clock security operations capability covering all endpoints and network infrastructure.

03

Regulatory Compliance

Ensure full compliance with the Protection of Personal Information Act (POPIA) and ISO/IEC 27001.

04

Six-Month Delivery

Deliver a fully operational CyberShield system within six months with complete documentation and staff handover.
